# Glosario

| Término | Significado |
|---|---|
| **Sección** | Grupo de alumnos de un grado en un año (p. ej. «1° de Primaria · A») |
| **Malla curricular** | Cursos y horas semanales de cada grado |
| **Asignación** | Docente ↔ curso ↔ sección |
| **Bloque horario** | Franja del día (clase o receso) de un turno |
| **Pre-matrícula** | Reserva de cupo antes del pago; vence si no se paga |
| **Ratificación** | Matrícula masiva del año siguiente para alumnos que continúan |
| **Cuota** | Monto a pagar por un concepto (matrícula, pensión) con vencimiento |
| **Concepto / tarifa** | Qué se cobra / cuánto, por año y grado |
| **Criterio de evaluación** | Componente de la nota con peso (suma 100 %) |
| **Literal** | Nota en letras de Primaria (AD, A, B, C) |
| **Libreta / boletín** | Resumen de notas de un alumno / PDF oficial del periodo |
| **Gateway** | Punto único de entrada que valida el token y reenvía |
| **Eureka** | Registro donde los servicios se anuncian y se encuentran |
| **Config Server** | Servicio que entrega la configuración por ambiente |
| **Feign** | Cliente HTTP declarativo entre servicios |
| **Outbox** | Tabla donde el evento se guarda junto al dato y se publica después |
| **DLT** | Cola de mensajes que no se pudieron procesar (*dead letter topic*) |
| **ShedLock** | Candado para que un job programado corra en un solo nodo |
| **Réplica local** | Copia mínima de datos ajenos (`matriculas_local`) mantenida por eventos |
| **PKCE** | Flujo de login que evita que la app maneje la clave |
| **JWKS** | Claves públicas para validar el JWT |
| **Espacio de trabajo (hub)** | Grupo de pantallas del menú reunidas en pestañas |
| **MRV / lista tabú** | Heurísticas del armado automático de horarios |
| **SIAGIE** | Sistema del Ministerio de Educación para la matrícula escolar |
